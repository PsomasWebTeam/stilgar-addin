# The Stilgar Outlook button (add-in)

The `addin\` folder is the whole Outlook add-in: a static page served from GitHub Pages
(public repo `PsomasWebTeam/stilgar-addin`, pushed by `python deploy_addin.py` from this
private repo) that reproduces the **New Legal Hold** page of Stilgar's wizard inside an
Outlook task pane.

- `manifest.xml` — the add-in definition. Mailbox 1.13 + `SupportsNoItemContext`, so in
  classic Outlook the **Start New legal hold** button on the Home ribbon works with no email
  selected; new Outlook and the web open it from a selected message's **Apps** menu.
- `taskpane.html` / `taskpane.js` / `taskpane.css` — the pane. Field for field the wizard
  (doc-production toggle, project number/name, the optional Terry recipient, time
  parameters + key words, the tripwire line, "Looks right", the blue Start button), plus
  Terry's billing-list request composed live underneath, editable.
- `config.js` — GENERATED by `tools/export_addin_config.py` from the Python package
  (`templates.BILLING_*`, `SIGNATURE_PAUL`, the cast, the holiday table, `ids.py`'s
  project-number rules). Never edit by hand; `tests/test_addin.py` pins the pane's
  rendering of Terry's email to `templates.billing_request`.
- `assets/` — icons from `psomas_icon.ico` (`tools/make_addin_icons.py`).

What pressing **Start Legal Hold** does: one POST to the **Stilgar Intake** flow
(`tools/build_intake_flow_package.py` builds its import package) with the request and
the standard queue payload; the flow writes the payload into `LegalHoldQueue\outgoing\`
(the existing **Legal Hold Email Sender** flow sends it from Paul) and the request into
`LegalHoldQueue\intake\`; any running Stilgar files the hold (`legalhold/intake.py`).

Try it without Outlook: `python tools/fake_intake_flow.py`, then open
`taskpane.html?dev=1&flow=http://127.0.0.1:8765/` in a browser.
